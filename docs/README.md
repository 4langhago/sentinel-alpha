## 읽을 때 주의

두 문서 모두 **확인된 사실과 추정을 구분해 표기**했습니다. 특히 온비드 문서는
`[확인]` / `[추정]` / `[미확인]` 태그를 씁니다. `[미확인]` 항목은 지어내지 않고
공란으로 두었으므로, 그 부분을 근거로 코드를 쓰지 마십시오.

### 이미 뒤집힌 결론

온비드 문서가 1단계로 권했던 구세대 엔드포인트 `openapi.onbid.co.kr` 은
2026-08-11 실측에서 응답하지 않았습니다(TCP 연결은 되지만 Empty reply,
같은 시점 `apis.data.go.kr` 은 정상). 해당 절에 경고 블록으로 표시해 두었습니다.
연동을 재개할 때는 `npm run onbid:probe` 로 현재 상태를 먼저 확인하십시오.

벤치마킹 문서의 기능 설명은 공개 검색 결과 기반이며 각 서비스를 직접 조작해
검증하지는 않았습니다.
